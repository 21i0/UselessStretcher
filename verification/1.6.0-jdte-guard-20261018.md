## 代码结论与修复

`WondrousStaffAcceleration.isEntityTargetAllowed` 是单体点击、范围发现和已保存实体标记的共享入口。新增注册 ID 黑名单：

- `jdte:time_accelerator_effect`：短时效果载体，原生寿命 15 tick，重复 tick 会提前消失。
- `jdte:ultimate_time_wand`：顶级时间手杖请求载体，每次原生 tick 提交加速请求并消耗自身剩余时间。
- `justdirethings:time_wand_entity`：JDT 原版时间手杖载体，自身 tick 执行额外工作并消耗寿命。

不添加强制依赖，不封禁整个命名空间。范围不创建这些目标的新标记；从旧 NBT 恢复的单体永久标记和范围标记在校验时只删除本模组标记，不删除或修改第三方载体。其它普通实体与机器继续加速。2i、时间流逝、奖励与自身载体的已有保护保留。

## 与 JDTE 的实现对比

参考当前上游源码 `rulanup/JDTE` 提交 `4c30d02a14597c7bc4f8f19ff7e33afb778267b8`（版本 0.6.4.6），保存在 `D:/AI/references/jdte-guard-20261018/`。前轮 0.6.4.5 参考也保留。实测 JAR 为 0.6.1.0 与 0.6.4.6；JDT 为 1.5.7。

| 项目 | 万象担架手杖 | JDTE 当前源码 |
|---|---|---|
| 普通机器 | 调用原生方块实体 ticker；兼容入口可替代或补充 | 原生 ticker；部分自有机器合并累计工作，遵守升级/红石工作条件 |
| AE | 原生 IGridTickable、多面节点去重、休眠与虚拟时钟桥 | AE 专用路由、网格服务和可选后端 |
| 驱动 | 单体保存为本模组标记，范围由世界 SavedData 调度 | 顶级手杖实体提交到统一工作队列；效果实体主要负责显示 |
| 工作预算 | 计数随 MSPT 降档，健康上限 1,000,000；协作全局 20ms、单目标 8ms | 默认全局 4096 回调/刻、每目标批次 64，可配置；全部机器模式可绕过全局计数预算 |
| 档位与时长 | 机器/完整实体最高 x1024；计时器独立最高 x32768；30 秒或两种永久模式 | 顶级手杖通常 x1024，顶级超频后最高 x32768；时长与资源规则由 JDTE 配置 |
| 原料与代价 | 保留机器自己的供电、物品、流体与产出条件，不另外收时间流体 | 手杖/机器有 JDTE 自身的 FE、时间流体与升级结算 |
| 实体目标 | 完整 tick 或特定工作计时器，支持预算与可选 AI 关闭 | 生物附加加速数据，完整额外 tick 时抑制 AI/移动等行为 |

两边的普通机器加速底层都是额外执行实际工作入口。JDTE 使用实体作为时钟/请求载体，不意味着应该把该实体再当工作目标加速。请求倍率不等于保证吞吐，第三方单次回调都不能由外层预算强制拆分。
