# 1.6.0 玩偶独立实现与声音同步验证

## 本轮改动

- 无 Poppet 前置、代码包、模型/动画 JSON 或私有运行库。保留 Minecraft Steve UV 上自行实现的大头短肢骨架、皮肤外层、八种物品待机及实体行走/摸头动作。
- 三段历史借用摸头声替换为纯数学合成的原创短旋律；新增柔和/明亮/自然角色音节与独立玩家声。音效脚本不读取任何参考录音，固定种子及 OGG 容器信息，重复生成哈希一致。
- 修复实体摸头声音仅有 sounds.json、没有注册 SoundEvent 而回退到悦灵声的问题。现在使用正式注册的 `useless_stretcher:two_i_pat`。
- 逐字显示和声音共用 Cue：仅在实际绘制帧推进，逻辑 tick 不抢先发声；每帧最多一个事件，长卡顿丢弃时间积压而不补播音频。标点、省略号共同停顿；Unicode code-point 不拆代理对，组合重音/变体选择符与前字一起显示。
- 六章 90 句分别安排语气（72 句 2i、18 句玩家），六句包含简中/繁中/英语义转折。问句末四个发声字明确上扬，不由固定循环决定。
- 快进、瞬显、回顾、隐藏、关闭及时停声；缩放不重置剧情/声音进度。设置说明下移，避免与声音开关重叠。

## 验证方式

- 客户端：`gradlew.bat -Pneo_version=21.1.249 -PstoryTests runStoryPreview -x prepareStoryPreviewMods --console=plain`。
- 隔离客户端包含本体 2.4.5.11、AE2 19.2.17、GuideME 21.1.17、Manaita 0.1.0、EIO 8.2.11-beta，不含 Poppet 或 GeckoLib。六章中英宽窄界面 96 张截图，玩偶多个姿势及真实物品显示上下文、庭院蓝图预览。
- 新断言涵盖每字音节对应、三速播放、Unicode/标点合并、长卡顿不爆音、多 tick 无绘制不发声、情绪音色/力度/速度差异、句内转折、问句末音上扬、暂停恢复/缩放/跳过/关闭不重复及音效资源注册。
- 服务端：`gradlew.bat -PregressionTests runRegression --console=plain`，NeoForge 21.1.219、本体 2.4.5.11、AE2/GuideME；12:03 完整通过，74 个实际样板、加速/仓库/玩偶回归、真实摸头调用与原创声音注册均通过。缺失可选模组按已有 fixture 显式跳过。
- 实际 Java Cue 导出后，由 `docs/render_dialogue_voice_preview.py` 根据生产 OGG、时间戳、音高、音量生成六段中英试听，产物仅在 `build/audio-preview`，不打包。
- 最终客户端于 12:05 通过 `STORY CHECKS PASSED`，玩偶真实物品显示区域两帧 697 像素变化；设置页截图已确认按钮不再遮住说明。
- 普通构建成功，包内 56 个 JSON/MCMeta 可解析，17 张剧情图和 7 个原创 OGG 与生产资源同哈希，无测试类/旧维度/参考模组文件。JAR 12170282 字节，SHA256 `209BE5FBFAC8FECE8782353EB97127F14EF80FDFD4D3074CFCFBF10E9D3CEF6A`。

## 限制

- 音效是角色化短音节，不是 TTS，不宣称按汉字真实发音；“可爱”的主观听感仍请用户试听。
- 哈希无匹配证明未保留相同字节资源，不构成全面法律保证。皮肤与剧情图片仍是用户提供素材，需要有相应分发权。
- 当前只做本地测试交付，不推送。仅支持新存档、最低无用之物 2.3.7、客户端与服务端同包的前轮约束不变。
- 无用户完整整合包、真实多人或全部光影实测；客户端现有 EIO 可选 Athena 模型资源警告不属于本次玩偶资源。
