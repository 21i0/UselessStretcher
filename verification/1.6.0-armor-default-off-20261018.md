# 1.6.0 有用锭装备默认关闭与 JEI 隐藏

日期：2026-10-18。继续版本 `1.21.1-1.6.0`、协议 20、NeoForge 21.1.249、最低无用之物 `1.21.1-2.4.6`。沿用用户已授权的源码提交与推送；本轮不创建标签或 Release。

## 最终规则

- 新增服务端 `useful_armor.enable=false`，控制整套装备的创造模式功能。原 `useful_armor.enable_recipes=false` 保留，合成须同时开启两个开关。
- 关闭功能时穿齐也不会切换或锁定创造；已被套装切换的玩家在下一次玩家 tick 恢复原模式，即使仍穿全套。直接模式切换与命令共用的底层保护也随总开关解除。
- 四件装备始终加入 `c:hidden_from_recipe_viewers`，开启功能后仍隐藏。使用 JEI 原生标签机制，无需生产插件或新增强制依赖；`replace=false` 不覆盖其它模组的隐藏项。
- 保留物品注册、创造栏获取、钻石甲属性、动画物品图标和隐藏装甲层。总开关关闭的是新增创造模式套装功能。
- 服务端配置通常在 `config/useless_stretcher-server.toml`；已有世界内同名 `serverconfig` 文件时以世界内文件为准，配置按钮悬停显示实际路径。本轮两个真实运行目录生成的配置均为两个开关 `false`。
