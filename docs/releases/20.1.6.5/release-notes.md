# 万象担架 20.1.6.5（Forge 1.20.1）

手杖升级为统一八标签窗口，新增绑定 AE 网络的源流体采集，以及担架整库装入机器样板槽。修复胶囊地图闪烁、AE2 陨石半截和 2i 鼻涕显示；保留现有六章剧情与玩偶玩法。

- 新增简体中文、繁体中文和英文配置界面；手杖统一窗口支持搜索、拖动和缩放。
- 流体采集默认关闭；部分提交有记录，接收量未知时持久隔离，避免重试复制。
- 整库装槽支持实时刷新、跨维度引用和被动轮转。
- 修正陨石绝对中心与包围盒。已完成的胶囊保留玩家改建，不重放结构或战利品；可主动创建相邻新实例。
- 对齐 MEK / Generators 与 Applied Mekanistics 兼容依赖，减少正常诊断日志刷屏。
