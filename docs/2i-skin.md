# 2i 换皮肤接口

2i 的实体、物品栏图标、主副手、掉落物、展示框和已放置摆件，共用：

`assets/useless_stretcher/textures/entity/two_i.png`

替换这一个 PNG 即可统一换肤，不需要重新画物品图标或为各形态分别贴图。

- 皮肤使用标准 **64×64 Steve（四像素手臂）或 Alex（三像素手臂）** 布局，也支持相同比例的整数倍高清皮肤。按 Alex 标准保留手臂末尾透明列即可自动识别；客户端在重载时只适配手臂 UV，原 PNG 不会被改写。
- 帽子、上衣、袖子、裤子的第二层正常保留，跟随对应骨骼运动。
- 不添加额外嘴巴贴图，也没有嘴巴动画；原始 PNG 不改写，眨眼通过重载时生成的眼部纹理实现。
- 立绘和 Galgame CG 是独立美术资源，不会由 Minecraft 皮肤自动生成。

## 用资源包替换

资源包根目录放 `pack.mcmeta`，再按上面的完整目录结构放新皮肤：

```json
{
  "pack": {
    "pack_format": 34,
    "description": "2i 自定义皮肤（Minecraft 1.21.1）"
  }
}
```

把资源包放进客户端的 `resourcepacks`，在资源包界面启用。更新图片后按 F3+T 重载即可，不必更换世界中的玩偶。多人游戏中每位客户端需要使用同一资源包，或由服务器分发资源包。

## 维护说明

源路径固定为 `TwoIDollRenderer.TEXTURE`，实际渲染统一取 `TwoIDollSkin.texture(model.blink())`。加载资源时处理一次 Alex 手臂到 Steve UV 的适配及眼部纹理生成，保证手掌底面完整，袖子外层的透明区域保留；每帧不读 PNG。所有形态共用大头、短手短脚骨架，整体尺度为 0.62。实体只是同一只坐姿玩偶站起身；坐姿双脚自然向外分开。

第一人称使用玩家自己的手臂和袖子托住玩偶底面，支持左右惯用手与副手，保留装备/挥手动画；仅持有 2i 时接管该手渲染。第三人称也把支点改到玩偶底部。待机和惯性动画仅在客户端计算，没有假生物或逐帧数据包；陪伴好感由服务端每秒采样，在需要时更新关系组件。摆件保存完整 ItemStack，放置、破坏掉落、Shift 回收均保留组件。

2026-10-12：所有形态共用较长躯干和四肢比例。眨眼保持头部形状，只改脸部 UV 的两只眼睛：当前皮肤布局 x=9..10 / 13..14，y=14（HD 皮肤按整数比例放大）；闭眼颜色采自相邻皮肤和眉毛。替换皮肤若眼睛位置不同，应对应调整眨眼区域；透明头发外层保持透明。天气配件使用独立原创纹理，不会给衣服染上伞的颜色。
