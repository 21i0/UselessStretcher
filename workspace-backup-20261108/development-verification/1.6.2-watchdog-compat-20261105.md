## 实现

1. 在普通机器 ticker 与 AE 服务发现之前，识别 JDTE 通用批处理接口，或无 JDTE 时的 PBG 自有接口。只向原生银行入账，不同时重放完整 ticker、AE 服务或虚拟世界时钟。
2. 各加速来源按服务器和 BE 对象身份合并，每真实 tick 至多 flush 一次。旧积压在下一 tick 预算重置后优先处理；新贡献在 tick 末处理。共享时间预算和单目标预算仍有效；单目标用尽让位给其它目标。
3. 执行第三方 void 回调后发生异常时，提交量未知：暂停该 BE 实例的额外加速、限为一次告警，不回退或重放。机器正常 tick 保留；新实例不会继承旧实例暂停。失效、卸载或被替换的目标不加载区块执行。
4. 精确 LDLib2 2.2.44、MBD2、AE2、AE2LT 同时存在时，将 MBD2 标准 managed sync 从 LDLib worker 移到主线程。其它异步回调保留。每机器合并，128 项/2ms 软预算；失败至少 20 tick 退避，错误日志每机器最多 60 秒一次。重试恢复完整 dirty set，避免前半段同步清标记后丢失字段。
5. AE2LT 的主线程保护保留，不异步访问 SavedData、不阻塞生产 worker 等待主线程、不修改第三方 JAR。

PBG **1.0.9 原本已经具备**银行、真实 tick 去重、IO 配额及退避，不把它们误写成新版才有。准确源码/官方工件审计见 `watchdog-20261105/third-party/coalesced-contract-audit.md`。

时间预算为合作式限制，不能中断已经进入的单次第三方同步回调；不能保证任意 AE 网络单次 insert 都迅速返回。第三方银行是否持久化由其实现决定，本层不保存或自动重放未知提交。

真实配方和流体使用原生机器、配方及 AE storage service；挂载的后端是可观测的测试 MEStorage，不是原服务器磁盘网络。手动 Post flush 往往受 PBG 当 tick 门控跳过，由下一 tick 原生处理银行，因此记录的 maxFlushNanos 不代表完整配方/AE IO 延迟，也不能外推为原服务器性能保证。重启验证覆盖正常保存关闭，不覆盖突然断电的跨文件原子性。MBD2 实际序列化中断后的完整恢复由源码审查及队列故障测试覆盖，未向真实 MBD2 字段注入故障。

当前修补只修改隔离分支；原主工作区未提交的玩偶变更、其它未跟踪文件与 1.20.1 分支均保留。
