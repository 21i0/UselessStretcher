# 荒辰移晷之杖

<ItemImage id="useless_stretcher:wondrous_staff" scale="5" />

荒辰移晷之杖继承无用之物造化垂青之杖的采集、时运、保护和其它已启用功能，并增加时间加速。它的时运/精准采集模型沿用材质作者虾比提供的动画材质。

## 合成与按键

<Recipe id="useless_stretcher:wondrous_staff" fallbackText="此配方已被当前整合包移除。" />

无序合成：万象担架和无用之物的造化垂青之杖（`useless_mod:endless_beaf_item` 或兼容的工具标签）。

手杖的加速设置按键默认为 X，可以在“设置 → 按键控制”中改键；物品提示和 GuideME 页面会显示当前按键。无用之物的 G 按钮仍用于打开原版手杖功能配置。

第一次把手杖拿到主手或副手时，会提示“手杖的加速 UI 为 X”。若没有打开界面就直接右键加速、Shift 滚轮换挡，系统还会补充提示，最多提示三次。

## 总开关与倍率

在无用之物 G 配置页打开“时间加速”，或在本模组 X 配置页右上角打开同一个开关。两个界面修改的是同一份物品组件数据。

Shift+滚轮可以循环切换：关闭、x2、x4、x16、x32、x64、x128、x256、x512、x1024。X 页面按钮和滚轮完全同步，切换后另一处会显示最新倍率。

## 加速普通机器

开启时间加速后，手持手杖对机器 Shift+右键。普通方块实体会重复执行自己的方块实体 tick；只有能够安全识别的目标才会被推进。加速中的机器会显示流光溢彩边框，进入空闲动态降频时边框变回金色。

避雷针是专门的有效目标：时间加速开启时，普通右键避雷针会由本手杖接管，持续生成非天气闪电，不再落入无用之物原版的单次召雷交互；切换到关闭后不会继续生成新的闪电，关闭加速时原版召雷行为保持不变。避雷针也可以被范围加速框选，并按范围的加速黑名单/白名单规则处理。

普通机器的加速不等于无条件强行改变内部计时器：机器自身的能量、物品、流体和输出逻辑仍由它自己的代码处理。高倍率会增加服务器工作量，请逐步提高倍率。

## 加速 AE2 机器和节点

AE2 设备可能不依赖普通方块实体 tick，而是依赖 ME 网络节点的 `IGridTickable`。手杖会直接推进不同的 AE 网格 tick 节点，同一个节点通过多面连接时只计算一次；节点报告休眠后会停止本刻剩余的空调用。

这意味着以下两类 AE 设备都可以加速：

* 需要 ME 网络的 AE2 机器、样板提供器、分子装配室等，会按 AE 网格 tick 工作。
* 只使用 FE 供电、没有接入 ME 网络的 AE 兼容机器，也可通过其公开的普通 tick 或 AE 节点服务推进，不额外要求连接 ME 网络。

AE2 的网格供电、频道和网络连接规则不会被跳过。没有电、没有材料或机器自身处于关闭状态时，加速不会凭空产出物品。

单体和范围加速使用相同的机器兼容规则。普通机器安装 ME 接口后仍保留自己的生产 tick；范围名单之外的机器和整个 ME 网络不会被连带加速。

## 加速实体、日月和天气

Shift+右键动物或其它非玩家实体，会重复执行完整实体 tick；成长、繁殖冷却、移动、效果和模组实体逻辑都会随之推进。实体加速时默认关闭 Mob AI，结束后恢复原状态；可在配置中关闭“实体加速时关闭 AI”。实体头顶的进度条属于世界渲染，会跟着实体移动，不是 HUD。

X 界面的“生物加速设置”可以单独切换两种实现：旧手杖、旧加速目标默认保持“完整实体 tick”，继续使用主界面的最高 x1024 档位；新增“生物计时器”模式使用独立的 x2 至 x32768 档位，不改变机器、范围或日月的倍率。

计时器模式对齐无用之物的低开销生物加速：快进幼年成长、繁殖后冷却、成年鸡产蛋等待和正在下蛋的海龟；成年羊恢复羊毛，蜜蜂恢复携蜜状态并清除相关等待；村民需要补货时每秒最多补货一次。它不重复执行实体 tick，不加速移动、寻路或模组自定义逻辑，也不会缩短求偶窗口和药水时长。鸡到期后由下一次正常实体 tick 产蛋，不是每刻直接生成倍率数量的鸡蛋。生物自身的其它条件和服务端 AI 开关仍然生效。

两种实现都支持主界面的普通 30 秒或永久持续模式。更改实现或计时器倍率后，需要重新对目标 Shift+右键应用；把主倍率切到关闭后再对目标操作，仍会取消加速。高计时器倍率不会增加完整 tick 的循环次数，但不代表生物本身及其产物完全不占性能。

准星对准太阳或月亮并 Shift+右键，可以加速昼夜、天气和原版云层。它遵守 `doDaylightCycle` 和 `doWeatherCycle`，只处理天空相关时间，不会顺带推进机器、计划刻或其它世界逻辑。日月始终是普通 30 秒模式，不支持永久模式。

## 三种持续模式

* **普通模式**：目标加速 30 秒后停止；普通模式始终满速，不启用动态降频。
* **永久模式**：机器、AE 节点和实体持续加速；空闲目标可以进入动态降频以节省性能。
* **永久模式（无休眠降频）**：持续加速并跳过动态降频，适合不能被判定为空闲的工作机器。

把倍率切到“关闭”后，再对同一目标 Shift+右键可以停止该目标。永久模式不会改变 UI 选择的倍率，也不会把缓存挂在玩家身上；目标关闭后其工作缓存会被清理。

单体、实体和范围加速共用自适应预算与单目标时间限制，超出预算的工作会顺延；x1024 是请求倍率，实际吞吐还取决于机器开销、供能和物流。普通模式与无休眠模式不做空闲检测；动态降频不会遍历超大虚拟库存，缺少可观察接口或读取异常时保持加速。

## 附加功能

自动熔炼由无用之物本体提供，手杖不再注册重复的自动熔炼开关；请按无用之物当前版本的 G 配置使用本体功能。

点击“（展开）”可看到收纳的附加功能。“战利品箱刷新（原版也刷）”需要先在配置中开启 `loot_refresh.enable`，该配置默认关闭；开启全局配置后，还需在每把手杖的 X 界面打开自己的功能开关。手持手杖 Shift+右键带战利品表的原版箱子、木桶或容器矿车，会清除旧内容并按原战利品表重新生成。已安装本模组后打开过的容器仍可刷新；安装前就已打开且原版早已丢弃战利品表的旧容器无法可靠恢复，也不会把普通玩家箱子误判为战利品箱。安装 Lootr 时会调用其官方刷新接口，同时重置所有玩家的独立库存和开启状态。

“召唤模式”默认受配置文件关闭。将 `summoning.enable` 改为 `true` 后，展开 X 配置页的附加功能并进入“选择生物并召唤”。列表只读取已同步的实体注册表，按模组 ID 分类，显示当前语言译名，同时支持中文、英文路径名、注册 ID 和模组 ID 搜索。勾选后点击“召唤”，每次最多生成 32 个唯一生物；生成的 Mob 会立即关闭 AI，不会自行寻路或攻击。

## 手杖模式标签

无用之物新版的 G 界面可以切换扳手标签、剪刀功能、打火石功能和其它工具能力。万象担架会保留手杖身份、倍率、模式和所有数据组件，切换“扳手标签”不会把手杖变回普通造化垂青之杖；扳手标签关闭后，手杖也不会再被 `c:tools/wrench` 或 `gtceu:crafting_tools/wrench` 识别为扳手。剪刀和打火石能力分别跟随无用之物对应开关同步。开启时间加速时，Shift+右键仍优先用于加速，普通工具能力在其它交互中保持可用。

Apotheosis 安装后，手杖按太初杖同样归入“破坏者/镐类”类别，不会再被识别为剑。
