# 万象担架附属

本模组界面的操作按钮、滑块、模具勾选和样板获取区均可悬停查看说明。高倍率生物计时器模式需在手杖 X 界面手动选择；默认仍保留原有完整实体 tick 模式。

本模组自有窗口可以拖动标题栏移动，拖动边缘或四角缩放。内容会重新排布，小窗口放不下的内容可滚动查看；右上角叠放方框恢复默认大小和居中，叉号关闭或返回上一层。窗口位置和大小保存在本机，不改变服务器设置、倍率或勾选状态。AE2 指南和无用之物原有 G 界面仍由对应模组管理。

万象担架是无用之物的 AE2 附属模组。万物之块可以集中管理无用之物万象合金炉使用的模具和 AE 样板，万象担架可以把样板送入远处的机器，荒辰移晷之杖则可以加速普通机器、AE2 设备、实体和范围内的目标。

本节内容已经并入 AE2 原有指南。安装 GuideME 后，在 AE2 指南左侧导航中打开“万象担架附属”；把鼠标放在本模组物品上并按 GuideME 的阅读键，也会直接跳到对应页面。按键显示会跟随游戏内的按键设置。

## 使用前准备

需要安装 Minecraft 1.21.1、无用之物、AE2，以及客户端可选的 GuideME。GuideME 只负责客户端指南界面；未安装 GuideME 时，本模组的机器、样板、担架和加速功能仍可正常使用。

无用之物 2.3.7 及更新版已经原生支持 4096 个样板槽位，万象担架会自动使用本体容量。旧版无用之物仍由本模组提供兼容处理；升级或回退前建议备份世界。

材质与游戏内鸣谢署名：虾比。
