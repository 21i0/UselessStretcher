# 合成配方

本页列出万象担架附属的主要配方。所有“无序”配方都可以在工作台任意摆放；需要 AE2 的配方只有在安装 AE2 时才有意义。

* 万象担架：万象万物之块 + AE2 空白样板。

## 配方与样板

这些工作台配方也可以被万物之块按机器/模组筛选获取，再由万象担架送入样板总成或被动合成仓。AE2 的普通合成样板、处理样板、锻造台样板和切石机样板仍由 AE2 自己编码；万象担架不会改变样板类型。
