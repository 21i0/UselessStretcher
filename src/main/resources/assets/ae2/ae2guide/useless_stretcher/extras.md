# 配置、彩蛋与升级

## 树叶掉落手杖

生存模式玩家亲手破坏原版或其它模组树叶时，有默认十万分之一（`0.00001`）概率获得荒辰移晷之杖。除 `#minecraft:leaves` 标签外，模组常见的树叶方块也会被兼容识别。

每个玩家、每个存档只会成功一次。成功后手杖优先进背包；背包满时会生成不可燃、不会自然消失的跟随掉落物，直到背包出现空位自动领取，不会被火烧掉或远距离丢失。首次成功会解锁紫色挑战“怎么打树叶也掉啊？”。

## 游戏内配置

配置文件为游戏目录的 `config/useless_stretcher-common.toml`。也可以在“设置 → 模组 → 万象担架 → 配置”中修改，点“完成/保存”后写回文件。

主要选项：

* `acceleration.idle_throttle`：永久模式和选择休眠降频的范围是否对空闲机器降频，默认开启。
* `acceleration.entity_disable_ai`：实体加速时是否关闭 Mob AI，默认开启；结束后恢复原状态。
* `staff_leaf_drop.enable`：是否开启树叶掉落手杖彩蛋。
* `staff_leaf_drop.probability`：树叶触发概率，默认 `0.00001`。
* 配方兼容选项：可隐藏 Ender IO 半自磨机重复的磨珠配方变体。

范围的倍率、名单、偏移和历史由世界数据保存；不需要把配置或范围缓存放进玩家 NBT。修改配方目录过滤后，按游戏提示重载世界或重启游戏。

## 四种旧维度方块

四联、九联及各自奇数中心维度保持无用之物的固定白昼、无雨、无雷判定。Dyson Cube Project 等太阳能设备在露天且上方无遮挡时可以正常工作；本模组不会改变这些维度的天空外观，也不会修改其它维度的昼夜和天气规则。

多联维度方块已经由无用之物新版本本体接管。旧存档中的方块仍会保留兼容，新的世界应使用无用之物提供的本体方块。

## 升级提醒

客户端和服务端应同时更新。1.4.1 起样板获取使用按机器倒排索引、指纹去重和会话缓存；大容量模具保存在服务端，不再把完整列表写进掉落物。无用之物 2.3.7+ 已原生提供 4096 样板槽位，万象担架不会重复启用旧版扩容。升级前请备份世界，回退旧版时也请恢复备份。
