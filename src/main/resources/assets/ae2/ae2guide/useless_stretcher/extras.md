# 配置、彩蛋与升级

## 独立传送键

在控制设置的万象担架分类中绑定“独立传送”，默认未绑定，不需要携带手杖。直接按键向准星方向瞬移；潜行＋按键使用 Ender IO 旅行锚。瞬移会检查落点，旅行锚需要对应模组和有效目标，两者都遵守服务端传送事件与短冷却。

## 树叶掉落手杖与玩偶

生存模式玩家亲手破坏原版或其它模组树叶时，有默认十万分之一（`0.00001`）概率获得荒辰移晷之杖。除 `#minecraft:leaves` 标签外，模组常见的树叶方块也会被兼容识别。

2i 玩偶独立按默认万分之一（`0.0001`）概率抽取，不需要先抽中手杖。手杖与玩偶各自每位玩家每个存档只会成功一次，分别保存抽中与领取记录。

奖励优先进背包；背包满时保留待领取记录与不可燃、不会自然消失的安全跟随载体，空出位置后自动领取。重登和正常保存重启不会重复发放，丢弃或转送奖励不会重置机会。首次抽中手杖会解锁紫色挑战“怎么打树叶也掉啊？”。

## 游戏内配置

手杖配置页展开后可切换“辐射防护”，默认关闭。安装 Mekanism 时，开启的手杖只要留在背包或双手中，就会清除自身已有辐射剂量并持续免疫；关闭或移走后恢复普通辐射规则。这个开关保护持有者，不会移除世界中的辐射源。

维度胶囊地图下方会显示当前生成阶段和进度条。规划阶段使用活动指示，之后依次显示清理、结构放置、基岩铺底和收尾进度，完成时为 100%。暂停、保存和继续会保留进度；关闭界面后任务仍会继续。

新结构集中存放在胶囊自己的空白世界，并自动采用原结构所属世界的高度、群系和环境规则。同一环境的结构相邻摆放，不会生成整片自然地形。再次进入会回到原来的结构；只有选择生成相邻实例才会新建。此前 1.6.0 测试包保存的胶囊实例仍保留原位置和入口。

所有配置（包括高亮显示）统一收纳在模组配置页的“服务端配置”分类。单机或局域网主机进入世界后，在“模组 → 万象担架 → 配置 → 服务端配置”中修改，返回最外层配置页时保存并同步给在线玩家。联机玩家不能用自己的配置覆盖服务端。

专用服务器由服主编辑 `config/useless_stretcher-server.toml`；如果世界的 `serverconfig` 目录已有同名文件，则以世界内文件为准（单机通常为 `saves/世界名/serverconfig/`，服务器通常为 `world/serverconfig/`）。配置按钮悬停可查看当前实际文件路径。首次升级会在没有服务端配置及默认模板时导入旧 `useless_stretcher-common.toml`，旧文件保留备份，以后修改服务端文件即可。

主要选项：

* `acceleration.idle_throttle`：永久模式和选择休眠降频的范围是否对空闲机器降频，默认开启。
* `acceleration.entity_disable_ai`：实体加速时是否关闭 Mob AI，默认开启；结束后恢复原状态。
* `summoning.enable`、`loot_refresh.enable`：召唤生物、战利品箱刷新，默认关闭，各自独立控制。
* `staff_leaf_drop.enable`：是否开启树叶掉落手杖彩蛋。
* `staff_leaf_drop.probability`：树叶触发概率，默认 `0.00001`。
* `doll_leaf_drop.enable`、`doll_leaf_drop.probability`：独立玩偶掉落开关与概率，默认开启、`0.0001`。两种奖励的开关互不影响，关闭新抽取不会删除待领取奖励。
* 配方兼容选项：可隐藏 Ender IO 半自磨机重复的磨珠配方变体。

范围的倍率、名单、偏移和历史由世界数据保存；不需要把配置或范围缓存放进玩家 NBT。修改配方目录过滤后，按游戏提示重载世界或重启游戏。

## 多联维度与星空庭院

多联维度请使用无用之物本体的对应功能。本附属旧四联、九联及奇数中心维度的方块、注册和生成器已经彻底移除。

2i 的星空庭院是独立的永夜超平坦维度。好感达到 100 后接受邀请即可前往，之后允许重游；创造存储元件奖励每位玩家每个存档最多 8 个。在星空中按玩偶收回键（默认 B）安全返回。

## 升级提醒

客户端和服务端应同时更新。1.6.1 最低需要无用之物 2.4.6，旧版扩容补丁已经删除。样板索引、去重缓存与大容量模具服务端存储仍然保留。由 1.5.x 升级时请使用新存档；由 1.6.0 升级不需重置存档，胶囊实例保留原位置和入口。详细操作见[维度胶囊](capsule.md)。
